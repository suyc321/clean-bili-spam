# B站内容净化助手

Chrome / Edge 浏览器插件，帮你清理 B 站首页，并识别营销号。有两个主要功能：

1. **遮挡 / 隐藏首页推广**：完全免费，装上就能用，不需要账号、不需要 AI、不需要任何额外权限。
2. **AI 识别营销号**：可选。需要你自己的 AI 接口（付费 API，或本地部署的模型），费用由你和服务商结算。

两个功能互相独立。不配置 AI，第一个功能照常工作。

## 功能一：遮挡 / 隐藏首页推广

B 站首页的推荐位里混着不少不是投稿的内容：商业广告，以及番剧、国创、综艺、课堂、直播等官方强插。插件识别出这些卡片，按你的选择处理：

| 档位 | 效果 |
|---|---|
| 不处理 | 保持页面原样 |
| 遮挡（默认） | 在卡片上盖一层遮罩，写着「已遮挡广告」，不可点击 |
| 直接隐藏 | 卡片从页面消失，后面的卡片自动补位，不留空洞 |

- 遮罩颜色可选纯黑、纯白、灰色。
- 往下滚动加载出来的新卡片也会自动处理。改完设置，已打开的首页立刻生效。
- 识别规则很保守：卡片里有链接，并且没有任何一个指向投稿（`/video/`），才会被处理。带投稿链接的卡片一律不动。
- 只读取页面已经渲染出来的内容，不拦截或修改网络请求，不发送任何数据。
- 目前处理的是首页推荐。B 站改版后选择器可能失效，欢迎提 issue。

在设置页「广告和强插」里切换档位和颜色。

## 功能二：识别营销号（可选）

在 B 站首页、搜索结果和 UP 主主页的视频卡片上挂徽章，提示这个账号是不是值得留意。它分两层：

**本地提示（不需要 AI）**：看到明确事实时，徽章显示「值得复核」，并在面板里列出依据：

- 简介含侵权免责声明
- 投稿标题兜售成套可下载资源
- 同一投稿也出现在其他账号名下
- 24 小时内投稿不少于 5 条

**AI 判定（需要你自己的 AI 接口，默认关闭）**：

- 在设置页填写接口地址、API Key、模型名和接口格式，可以测试连通性。支持 OpenAI Chat Completions、Anthropic Messages、OpenAI Responses 三种格式。
- 配置后，滚动加载到的新账号会自动判定，一次一个；卡片上也可以手动再判一次。弹出页「AI 判定本页」一次最多处理 10 个还没有结论的账号。
- 输出按固定格式校验：分类、概率、理由，以及模型自己声明的证据不足项。徽章显示概率，面板展示理由。
- 结论只缓存在本机，7 天后过期。判定记录可查看，含提示词版本。
- 概率达到 80 时，可以选择用遮罩弱化该卡片（弱化的卡片不可点击，徽章和处置面板仍可用）。
- 判定口径可以在设置页改成你自己的标准。

**拉黑与名单**：

- 在徽章面板里二次确认后，才会调用 B 站的关系接口拉黑，不会自动拉黑。首次使用需要在设置页授权。
- 弹出页可以按概率档批量拉黑，单次最多 10 个；完成后刷新页面可继续处理其余账号。
- 白名单、忽略名单、待处理清单都只存在本机。
- 可选开启「补全简介和粉丝数」：读取 UP 主公开名片，供本地提示和 AI 使用。默认关闭。

插件不按观点或立场过滤账号。徽章上的概率是模型的判断，不是事实认定，也未经标注集校准。

## 安装

本项目不上架应用商店，通过「加载已解压的扩展程序」使用。

1. 到 Releases 下载构建好的 zip 并解压；或者自己构建：`npm.cmd install`，再 `npm.cmd run build`，得到 `dist` 目录。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`。
3. 开启开发者模式，点「加载已解压的扩展程序」。
4. 选择解压出来的目录（自己构建就选 `dist`）。
5. 打开或刷新 B 站页面。

浏览器会提示「开发者模式扩展」，这是正常的。这种方式不会自动更新，升级时重新下载，并在扩展页点「重新加载」。

内容脚本只注入 `www.bilibili.com`、`search.bilibili.com`、`space.bilibili.com`。

## 隐私与权限

- 安装时只有 `storage` 权限。只用遮挡 / 隐藏功能，不需要任何其他权限，也不发起任何网络请求。
- 开启 AI 并保存配置时，浏览器才会按你填写的接口域名申请访问权限；关闭或更换接口时会移除。
- 拉黑需要可选的 `cookies` 权限（读取 HttpOnly 的 `bili_jct`）和 `api.bilibili.com` 主机权限（调用 B 站关系接口）。两者都在设置页由你主动授权，只在本机使用。
- 不申请浏览历史或网络拦截权限，不保存搜索词、Referer、Cookie 或完整浏览历史。
- 未配置 AI 时不上传任何数据。配置后，自动判定会把账号昵称、简介、最多 20 条投稿标题和发布时间发到你填写的接口；开启「补全简介和粉丝数」后，还会带上粉丝数和投稿数。不发送 UID、Cookie 或浏览历史。
- 开发者不运营任何服务器，插件没有任何分析上报。API Key 只保存在本机，配置导出文件不含 Key。
- 设置页有一个「打印对话」开关，会把 AI 请求和响应打印到后台控制台，仅用于排查问题，默认关闭。

## 本地开发

技术栈：TypeScript、React（仅设置页和弹出页）、Vite + CRXJS、Manifest V3、IndexedDB（`idb`）、Zod、Vitest。

PowerShell 若拦截 `npm.ps1`，用 `npm.cmd`：

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run build
npm.cmd run verify
npm.cmd run verify:e2e
npm.cmd run demo
```

- `verify`：类型检查、单元测试、构建、产物自检。
- `verify:e2e`：真实扩展加本地脱敏页面，不联网。需先构建，并启动带扩展的 Edge。
- `demo`：`demo/` 直接运行生产模块里的触发器和徽章渲染，AI 结论用内置假数据，不发网络请求。打开 `http://127.0.0.1:8642/`。

目录结构：

```text
src/
  adapters/        # 页面 DOM 适配，不访问存储、判定或网络
  ai/              # AI 判定客户端
  application/     # 用例编排
  background/      # Service Worker：观察库、设置与 AI 结论的写入者
  content/         # 页面扫描、遮罩与 Shadow DOM 标签；拉黑请求在这里发出
  domain/          # 类型与设置
  features/        # 本地触发器，纯函数
  messaging/       # 经校验的消息协议
  options/         # 设置与名单
  popup/           # 本页摘要
  storage/         # chrome.storage 与 IndexedDB
assets/branding/   # 图标源文件（SVG）；导出的 PNG 在 public/icons/
```

消息协议不接受任意 URL、选择器、脚本或接口路径。观察、设置和 AI 结论只由 Service Worker 写入；拉黑名单和拉黑请求在内容脚本里完成，Service Worker 只负责读取 `bili_jct`。
